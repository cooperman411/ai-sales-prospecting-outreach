# Preferred: native tools and an ordinary mailbox

The simplest supported workflow uses the AI assistant's own authenticated
company/web research, an approved contact source, and a mailbox with drafts.
No CRM is required.

1. Discover the actual host tools: web search, contact research, Gmail or
   Microsoft 365 read/draft/send, CRM reads/writes, and storage. Check scopes,
   account identity, tool errors, limits, and confirmation requirements.
2. If no contact-finding tool exists, use reputable public business sources or
   an optional Hunter native MCP connection before adding Composio.
3. When Gmail/Google Workspace is already connected, create **unsent drafts**
   only after authorization. A manual Gmail user can copy approved text and
   send it themselves. Do not assume the account is Workspace or has a
   particular daily quota.
4. Optional CRM: HubSpot's free CRM and Gmail extension can log emails in
   supported accounts; its paid-tier features and tracking may differ. Zoho
   CRM has a free edition, but direct Gmail integration is advertised in a
   paid Standard tier. Salesforce and others require account and permission
   checks. CSV works without any CRM.
5. Read-back every authorized CRM create or Gmail draft. No automatic owner,
   lifecycle, deal or suppression changes.

Use the provider-specific guide only after confirming a native connector is
unavailable or inadequate. Tool presence does not establish publish/send
permission.
